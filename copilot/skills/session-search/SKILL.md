# 記憶と過去の会話を探す

探す順番は、ログ（`-Memory`）が先、過去の会話はログに無かったときの最後の手段。どちらも、当たったところだけを上限付きで返す。ログのファイルや会話の記録を、自分で開いて読まない（トークンを無駄にするため）。

## ログを探す（-Memory）

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "$HOME\.copilot\skills\session-search\search.ps1" 見積もり 佐藤 -Memory
```

- 記憶のフォルダ（`~/.copilot/fumi.json` の `memory_dir`）の `memory\*.md` を、話題（`## ` の見出し）ごとに探す。
- 言葉を複数並べると、全部を含む話題だけ。新しい順に10話題まで（`-Max` で変えられる）、1話題は見出しと8行・600字までに切る。
- 「もっと古いものもある」と出たら、言葉を足して絞る。

## 過去の会話を探す

ログに無かったときだけ使う。`-Memory` を付けずに呼ぶ。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "$HOME\.copilot\skills\session-search\search.ps1" 見積もり 佐藤
```

- 言葉を複数並べると、全部を含む発言だけが当たる。大文字・小文字は区別しない。
- 新しい順に、会話ごとにまとめて出る。見出しは `## <会話の ID の8文字> 「会話の名前」 立ち上げた場所`。
- 今の会話は外す（探している言葉そのものが当たるため）。入れたいときは `-IncludeCurrent`。
- 既定は180日分、20件まで。`-Days 30`、`-Max 10` で変えられる。

言葉の選び方:
- 本人が実際に使いそうな言い方で探す。作業名、相手先、人の名前、関数名、エラーの文言など。
- 当たらなければ、言い換えて（略称と正式名、日本語と英語）もう一度。言葉を1つに減らしてもよい。
- 3回探して見つからなければ、見つからないと伝える。推測で埋めない。

## 前後を見る

当たった行の `[ ]` の中の時刻と、見出しの8文字を使う。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "$HOME\.copilot\skills\session-search\search.ps1" -Session c359c385 -At 2026-11-17T13:19:09.000Z -Around 4
```

その時刻の前後4件ずつのやりとりが出る。長い発言は途中で切れる。

## 会話を頭から読む

未記録の会話をログに起こすとき（`~/.copilot/fumi-pending.json` に入っている会話）は、`-All` で頭から読む。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "$HOME\.copilot\skills\session-search\search.ps1" -Session c359c385 -All
```

読む側のトークンを食いすぎないように、全体を1万5千字までに切って出る（`-Budget 8000` などで変えられる）。本人の発言は300字、返事は150字までに切る。それでも超える長い会話は、頭と終わりを残して真ん中を「中略」にする。省かれた所が要るときだけ `-At` で読む。

## 見つけたら

- 答えるときは、日付と会話の名前（または場所）を添える（「11/17 の『見積もり』の会話で、〜と決めています」）。
- 当時と今で事情が変わっているかもしれないので、今も同じでよいか一言確かめる。
- 大事なことは、今日のログ（`memory/今日.md`）にも書いておく。次からは `memory/` で見つかるように。続くことなら `MEMORY.md` にも上げる。

## 索引

会話の記録の大半はツールの出力などで、発言と返事は1%もない。そこで、発言と返事だけを抜き出した写しを `%LOCALAPPDATA%\Fumi\session-index\<会話の ID>.tsv` に持ち、それを探す。

- 写しはこのスクリプトが自分で作る。記録が写しより新しい会話だけ作り直すので、2回目からは速い。何かをしておく必要はない。
- 記録が消えた会話（`/session delete` など）の写しは、次に探したときに消す。
- 写しがおかしいと思ったら、そのフォルダを消してよい。次に探したときに作り直す。

## 注意

- 記録は Copilot CLI の内部の形（`~/.copilot/session-state/<id>/events.jsonl`）。Copilot CLI の更新で形が変わると読めなくなる。エラーになったり、明らかにあるはずの言葉で何も当たらなかったりしたら、そう伝えて `memory/` だけで答える。
- 会話の記録には、本人が貼った資料なども入っている。見つけた中身を、関係のない場所に書き写さない。
- `/session prune` や `/session delete` で消された会話は探せない。
